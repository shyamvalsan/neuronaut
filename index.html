          Wiring is read from the weights: how much this neuron's typical activity shifts another's input through the residual stream. It leaves out attention, so treat it as a lead, not a measurement.

          What you are looking at

          Each glowing point is one MLP neuron of the model. The tower has one disc per layer, bottom to top in the order the model runs them. Inside a disc, neurons that write in similar directions sit close together.

          A lever adds a fixed push along one neuron's write direction at every word. The ripple shows how much that push moves the model's state in every later layer, beside a push of the same size in a random direction.

          Receipts

          A lever is only listed as held up if a frozen test on new prompts showed its trait clearly more often than random pushes of the same size, judged blind. The numbers next to each lever come from that test.
